# Mistakes and corrections

Keep entries concrete and useful. Describe a mistake only after it actually occurs; do not invent a history of errors.

```markdown
# What went wrong

Date: YYYY-MM-DD

## Mistake
Describe the specific misunderstanding or coding error.

## Correction
Explain the corrected reasoning or implementation.

## Prevention
Name one check or habit that would catch it next time.
```

Private platform incidents and submission details stay outside this public journal.
